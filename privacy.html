Privacy Policy

Last updated: November 21, 2026

This policy explains how the Clipping tool used by the Yomi Mits channel handles data.

Who uses the tool

Clipping is a private tool. Only the owner of the Yomi Mits channel signs in to it. It is not offered to the public and it does not have other users.

What data it accesses

When the owner signs in with Google, the tool receives permission to manage the owner's own YouTube channel. It uses that permission only to upload videos to that channel and to set each video's title, description, tags and visibility.

The tool does not read, collect or store personal data from viewers or from anyone else.

How data is stored

The sign-in token is stored on the channel owner's own private server. It is not sold, shared or sent to anyone else.

YouTube and Google

This tool uses YouTube API Services. By using it you are also bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

How to remove access

Access can be removed at any time from the Google account security page: myaccount.google.com/permissions.
